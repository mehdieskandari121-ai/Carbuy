# CarBuyKhodro

اپلیکیشن موبایل فارسی و راست‌چین خریدوفروش و اجاره خودرو، با تمرکز اولیه بر خوزستان.

## وضعیت
- این مخزن قبلاً خالی بود؛ این commit آغاز پروژه است.
- نسخه اول شامل صفحه خانه، فهرست و جست‌وجوی خودرو، جزئیات آگهی، علاقه‌مندی‌های محلی و فرم ثبت آگهی نمایشی است.
- اتصال به API، احراز هویت واقعی، بارگذاری عکس و معاملات آنلاین هنوز در مراحل بعدی هستند.

## ساخت APK
از تب Actions، گردش‌کار `Build CarBuyKhodro Android APK` را اجرا کن. خروجی APK به‌صورت artifact قابل دریافت خواهد بود.

## توسعه محلی
نیازمند Flutter SDK و Android SDK است:
```bash
flutter pub get
flutter run
```
